# トランス☆ディスコ (trans-discord)

Discord Web版のチャット本文・フォーラムタイトルを逐次翻訳するChrome拡張機能（Manifest V3）です。

Reactの仮想DOMとChrome標準の「日本語に翻訳」機能が衝突してタブがクラッシュする問題を回避するため、原文には一切手を加えず、翻訳結果を新しい要素として追加する方式で動作します。

## 主な機能

- ポップアップ・詳細設定画面はブラウザの表示言語に応じて日本語/英語が自動切り替え
- クリックした発言だけを翻訳（自動翻訳ONの場合、最初の1クリックで以降は自動化）
- 翻訳エンジンとしてGoogle翻訳（無料・非公式エンドポイント）、DeepL API（無料/Pro）、Gemini API（ゲーム用語・スラングの解釈に強い）、ローカル翻訳（PLaMo 3 Translate、自分のPCで翻訳）を切り替え可能
  - 選択中のエンジンが失敗した場合は、DeepL → Gemini → Google翻訳の順に自動フォールバック（APIキー未設定のエンジンは飛ばす）
  - Geminiは無料枠（1分15回）の上限に近づくと送信せずに次のエンジンへ回す
- 訳文の右下に、実際に翻訳したエンジン名を小さく表示（フォーラムタイトルはマウスを乗せると表示）
- 翻訳元／翻訳先言語をそれぞれ指定可能（自動検出、ブラウザ言語への自動翻訳を含む）
- Gemini利用時は口調プリセット（フランク／丁寧／猫語／お嬢様／関西弁／カスタムプロンプト）を指定可能
- 日本語主体の発言・極端に短い発言をスキップするオプション
- メッセージが編集された場合の再翻訳
- 翻訳結果はブラウザを閉じるまで保持（上限1000件のLRUキャッシュ）。ポップアップから手動クリアも可能
- **DM（ダイレクトメッセージ）・鍵付きチャンネルでは自動的に動作を停止**（詳細は下記セキュリティ項目を参照）

## インストール方法（開発者モードでの手動読み込み）

1. このリポジトリをダウンロード（Code → Download ZIP）するか `git clone` する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`trans-discord` フォルダ（`manifest.json` があるフォルダ）を選択する

## 設定

- ツールバーのアイコンをクリック：拡張機能ON/OFF、自動翻訳ON/OFF、CAPTCHA確認ページを開くボタン
- ポップアップ内「詳細設定を開く」：翻訳エンジン、DeepL APIキー、翻訳元/翻訳先言語、表示ルールなど

## ローカル翻訳（PLaMo 3 Translate）の使い方

[Preferred Networks](https://www.preferred.jp/)が公開している翻訳特化モデル「PLaMo 3 Translate」を自分のPCで動かし、トランス☆ディスコから呼び出せます。翻訳はPC内で完結し、回数制限もありません。

### おすすめの手順（Windows・llama.cpp）

作者が動作を確認している手順です。

1. **モデルを入手する**：[pfnet/plamo-3-translate-2b-GGUF](https://huggingface.co/pfnet/plamo-3-translate-2b-GGUF) の「Files and versions」から `plamo-3-translate-2b-Q4_K_M.gguf`（約1.8GB）をダウンロードし、好きなフォルダに置く（例：`C:\tools\PLaMo3`。**フォルダの場所に空白を含めない**）。ダウンロード時にHugging Faceへのログインとライセンスへの同意を求められることがあります
2. **llama.cpp を入れる**（1回だけ）：ターミナルで次を実行し、終わったらターミナルを閉じる
   ```
   winget install llama.cpp
   ```
3. **起動用のbatを置く**：このリポジトリの [`tools/plamo/`](./tools/plamo/) にある `plamo-start.bat` と `plamo-stop.bat` を、ggufファイルと同じフォルダに置く
4. **サーバーを起動する**：`plamo-start.bat` をダブルクリックする。画面は出ず、裏で起動します（停止は `plamo-stop.bat`）
5. **接続する**：詳細設定で翻訳エンジンを「ローカル（PLaMo 3 Translate）」、サーバーの種類を「llama.cpp（llama-server）」にして「接続テスト」を押す。「接続OK：plamo-3-translate」と出れば完了です

補足：

- 接続テストが失敗するときは、同じフォルダにできる `llama-server.log` に原因が書かれています
- PCの起動と同時に立ち上げたい場合は、`Win + R` で `shell:startup` を開き、`plamo-start.bat` のショートカットを置きます
- batファイルの中身は、同じフォルダのggufファイルを読み、自分のPC（`127.0.0.1`）のポート8000で待ち受ける指定だけです。パスワードや個人の情報は含みません
- ブラウザがbatファイルのダウンロードを止めた場合は、GitHub上でファイルを開いて中身をメモ帳に貼り付け、同じ名前で保存してください

### その他のサーバー

- **LM Studio**：モデルを読み込み、開発者タブでサーバーを開始（既定 `http://localhost:1234`）。PLaMo 3 を読み込めるかは、LM Studioの版によります
- **llama.cpp（手動）**：`llama-server -m plamo-3-translate-2b-Q4_K_M.gguf -c 8192 --port 8000 --alias plamo-3-translate`
- **Ollama**：`ollama pull hf.co/pfnet/plamo-3-translate-2b-GGUF:Q4_K_M`（既定 `http://localhost:11434`）。接続を拒否される場合は、環境変数 `OLLAMA_ORIGINS` に `chrome-extension://*` を設定してOllamaを再起動する

補足：

- 接続先は自分のPC（`localhost` / `127.0.0.1`）に限ります
- 日本語に訳すときは、文体（です・ます調／だ・である調）を指定できます
- ポルトガル語はPLaMoの対応言語に含まれないため、他のエンジンで翻訳されます
- ローカル翻訳は、選択中のときだけ使います（他のエンジンのフォールバック先には入りません）

Built with PLaMo. モデルは本拡張機能に同梱しておらず、利用者が各自ダウンロードします。モデルの利用には [PLaMoコミュニティライセンス](https://plamo.preferredai.jp/info/plamo-community-license-ja) が適用されます。

## ⚠️ セキュリティ・プライバシーに関する重要事項（必ずお読みください）

この拡張機能は、翻訳のために **発言のテキストを外部サービス（Google翻訳・DeepL・Gemini）に送信します**（ローカル翻訳（PLaMo）を選んだ場合は、自分のPC内のサーバーにだけ送信します）。 利用にあたっては以下を理解した上で、自己責任でご利用ください。

### 1. 翻訳テキストの外部送信について

- **Google翻訳（無料・非公式エンドポイント）**：送信したテキストがGoogle側のサービス改善・モデル学習等に利用される可能性があります。Googleの一般的な利用規約が適用されます。
- **Gemini API（Google AI Studio）**：Google AI Studioの無料APIキーで利用します。無料枠の利用データはGoogleのサービス改善に利用される場合がある点に留意してください（有料枠の扱いはGoogle Cloudの規約に準じます）。Gemini AppやGemini Proなどのチャット向けサブスクリプションとは全く別のAPIキーが必要で、両者のログイン情報は流用できません。
- **DeepL API（Free / Pro）**：DeepLの規約上、翻訳処理後にテキストは保存されず、モデル学習にも使用されないとされています（Google翻訳よりプライバシー面で優れています）。
- **ローカル翻訳（PLaMo）**：テキストは自分のPCで起動したサーバー（`localhost`）にだけ送られ、外部には送信されません。ただし、フォールバックで他のエンジンに切り替わった場合は、そのエンジンに送信されます。
- どの翻訳エンジンを使う場合も、**機密情報・個人情報（本名・住所・認証情報など）が含まれるやり取りを翻訳させないこと**を強く推奨します。

### 2. DM・鍵付きチャンネルの自動除外について

本拡張機能は、以下に該当するページでは翻訳スキャン自体を行わないよう実装しています。

- ダイレクトメッセージ・グループDM（URLが `/channels/@me` で始まるページ）
- 鍵アイコンが表示されている非公開チャンネル

ただし、この判定はDiscordの画面構成（DOM構造）を独自に解析して行っている**簡易的なもの**です。Discord側の仕様変更や、判定ロジックが想定していないUIパターンによって、正しく機能しない可能性があります。**この機能を過信せず、機密性の高い会話ではそもそも拡張機能をOFFにする運用を推奨します。**

### 3. 翻訳結果のキャッシュ保持について

処理速度と通信量削減のため、翻訳結果は`chrome.storage.session`（ブラウザを閉じるまで保持される一時領域、上限1000件・古いものから自動削除）に一時保存されます。DM・鍵付きチャンネルはスキャン自体を行わないため通常はキャッシュにも乗りませんが、上記2.の判定漏れが起きた場合はキャッシュにも残ってしまいます。気になる場合は、ポップアップの「古い翻訳の削除」ボタンでいつでも手動消去できます。

### 4. APIキーの保存について

DeepL・GeminiのAPIキーは、Chrome拡張機能の `chrome.storage.local`（ブラウザのローカルストレージ）に **平文（暗号化なし）で保存されます。** 同じブラウザプロファイルにアクセスできる第三者がいる環境では、キーが読み取られる可能性があります。

- APIキーが流出・盗用された場合は、[DeepLのアカウントページ](https://www.deepl.com/account/api)や[Google AI Studio](https://aistudio.google.com/apikey)から**キーを破棄して再発行する**ことで被害を最小限にできます。
- 定期的にキーをローテーションする、共有PCでは使用しない、といった運用は利用者ご自身の判断で行ってください。
