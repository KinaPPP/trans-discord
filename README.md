# トランス☆ディスコ (trans-discord)

Discord Web版のチャット本文・フォーラムタイトルを逐次翻訳するChrome拡張機能（Manifest V3）です。

Reactの仮想DOMとChrome標準の「日本語に翻訳」機能が衝突してタブがクラッシュする問題を回避するため、原文には一切手を加えず、翻訳結果を新しい要素として追加する方式で動作します。

## 主な機能

- クリックした発言だけを翻訳（自動翻訳ONの場合、最初の1クリックで以降は自動化）
- 翻訳エンジンとしてGoogle翻訳（無料・非公式エンドポイント）とDeepL API（無料/Pro）を切り替え可能
  - DeepLが失敗・上限到達した場合はGoogle翻訳に自動フォールバック
- 翻訳元／翻訳先言語をそれぞれ指定可能（自動検出、ブラウザ言語への自動翻訳を含む）
- 日本語主体の発言・極端に短い発言をスキップするオプション
- メッセージが編集された場合の再翻訳
- **DM（ダイレクトメッセージ）・鍵付きチャンネルでは自動的に動作を停止**（詳細は下記セキュリティ項目を参照）

## インストール方法（開発者モードでの手動読み込み）

1. このリポジトリをダウンロード（Code → Download ZIP）するか `git clone` する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`trans-discord` フォルダ（`manifest.json` があるフォルダ）を選択する

## 設定

- ツールバーのアイコンをクリック：拡張機能ON/OFF、自動翻訳ON/OFF、CAPTCHA確認ページを開くボタン
- ポップアップ内「詳細設定を開く」：翻訳エンジン、DeepL APIキー、翻訳元/翻訳先言語、表示ルールなど

## ⚠️ セキュリティ・プライバシーに関する重要事項（必ずお読みください）

この拡張機能は、翻訳のために **発言のテキストを外部サービス（Google翻訳またはDeepL）に送信します。** 利用にあたっては以下を理解した上で、自己責任でご利用ください。

### 1. 翻訳テキストの外部送信について

- **Google翻訳（無料・非公式エンドポイント）**：送信したテキストがGoogle側のサービス改善・モデル学習等に利用される可能性があります。Googleの一般的な利用規約が適用されます。
- **DeepL API（Free / Pro）**：DeepLの規約上、翻訳処理後にテキストは保存されず、モデル学習にも使用されないとされています（Google翻訳よりプライバシー面で優れています）。
- どちらの翻訳エンジンを使う場合も、**機密情報・個人情報（本名・住所・認証情報など）が含まれるやり取りを翻訳させないこと**を強く推奨します。

### 2. DM・鍵付きチャンネルの自動除外について

本拡張機能は、以下に該当するページでは翻訳スキャン自体を行わないよう実装しています。

- ダイレクトメッセージ・グループDM（URLが `/channels/@me` で始まるページ）
- 鍵アイコンが表示されている非公開チャンネル

ただし、この判定はDiscordの画面構成（DOM構造）を独自に解析して行っている**簡易的なもの**です。Discord側の仕様変更や、判定ロジックが想定していないUIパターンによって、正しく機能しない可能性があります。**この機能を過信せず、機密性の高い会話ではそもそも拡張機能をOFFにする運用を推奨します。**

### 3. DeepL APIキーの保存について

DeepL APIキーは、Chrome拡張機能の `chrome.storage.local`（ブラウザのローカルストレージ）に **平文（暗号化なし）で保存されます。** 同じブラウザプロファイルにアクセスできる第三者がいる環境では、キーが読み取られる可能性があります。

- APIキーが流出・盗用された場合は、[DeepLのアカウントページ](https://www.deepl.com/account/api)から**キーを破棄して再発行する**ことで被害を最小限にできます。
- 定期的にキーをローテーションする、共有PCでは使用しない、といった運用は利用者ご自身の判断で行ってください。
